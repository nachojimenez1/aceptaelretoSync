# Privacy Policy for AceptaElReto to GitHub Sync

**Last updated: September 2026**

AceptaElReto to GitHub Sync ("the Extension") is committed to protecting your privacy.

### 1. Data Collection and Usage
- **GitHub Personal Access Token:** The Extension requires a GitHub Personal Access Token to commit code and create documentation on your behalf. This token is stored strictly on your local device using `chrome.storage.local` and is only transmitted directly to the official GitHub REST API (`https://api.github.com`). It is never transmitted to, collected by, or stored on any external server.
- **Problem Solutions and Metrics:** The Extension reads problem statements, source code, and execution metrics (time, memory) from `aceptaelreto.com` solely to format and upload your solutions to your designated GitHub repository.
- **No Analytics or Tracking:** The Extension does not collect personal identity data, browsing history, analytics, or telemetry.

### 2. Third-Party Sharing
We do not sell, rent, or transfer any user data to third parties. All network interactions occur exclusively between your browser, `aceptaelreto.com`, and `api.github.com`.

### 3. Contact
If you have any questions, you can contact the author via [GitHub](https://github.com/nachojimenez1/aceptaelretoSync).
